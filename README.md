# Ejercicio_s3_Js

# Reto JavaScript  “Workspace Inteligente” 
Desarrolla una mini aplicación web de tareas utilizando: 
• Manipulación del DOM 
• localStorage 
• sessionStorage 
El reto no está en hacer muchas funciones, sino en decidir estratégicamente qué 
información debe ser temporal y cuál debe mantenerse incluso después de cerrar el 
navegador. 
 # Objetivo 
Crear una aplicación donde el usuario pueda: 
• Agregar tareas 
• Marcar tareas como completadas 
• Eliminar tareas 
• Filtrar tareas: 
o Todas 
o Pendientes 
o Completadas 
Todo debe actualizarse dinámicamente usando JavaScript y el DOM. 
# Reglas del reto 
Deben usar localStorage para: 
Información que NO debe perderse al cerrar el navegador. 
Ejemplo: 
• Lista de tareas 
Deben usar sessionStorage para: 
Información temporal de la sesión actual. 
Ejemplo: 
• Último filtro seleccionado 
• Texto temporal de búsqueda 
• Mensaje de bienvenida 
# Requisito importante 
No basta con que funcione. 
Cada equipo deberá explicar: 
• Qué guardó en localStorage 
• Qué guardó en sessionStorage 
• La estructura de la información almacenada 
Restricciones 
No se permite: 
• Guardar todo en un solo storage “porque sí” 
# Bonus (Opcional) 
Puntos extra si implementan: 
• Modo oscuro persistente 
• Contador de tareas completadas 
• Edición de tareas 
Pregunta clave del reto 
“¿Toda la información debe guardarse para siempre?”
